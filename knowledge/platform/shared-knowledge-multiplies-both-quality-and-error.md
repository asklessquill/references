# Shared knowledge multiplies both quality and error

## Observation

A shared knowledge layer can reduce repeated context loading across agents and humans. The same mechanism can distribute stale, ambiguous, or incorrect assumptions across every consumer.

## Interpretation

The value of shared context grows with its reach, but so does contamination impact. Shared knowledge therefore needs stronger provenance and promotion rules than personal notes.

## Decision relevance

Separate raw reference material from validated organizational knowledge. Require explicit promotion, provenance, freshness, and revocation or supersession paths before broad agent consumption.

## Limits

Not all shared knowledge requires heavy governance. The level of control should match the consequence of an error.
