# Organizational features are valuable only when they solve an organizational problem

## Observation

Shared knowledge, centralized administration, seat management, SSO, workspace analytics, and organization-wide governance can be powerful, but their value may be low when the practical organization is a single human with multiple agents.

## Interpretation

Do not pay for organizational complexity simply because the platform is more capable. Coordination features should justify themselves by reducing real coordination cost.

## Decision relevance

Separate features that improve the individual's reasoning or execution from features that primarily coordinate multiple humans, teams, or identities.

## Limits

A single human may still operate many production agents and benefit from governance; the key is whether the coordination problem is real.
