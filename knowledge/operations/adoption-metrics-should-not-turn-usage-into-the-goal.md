# Adoption metrics should not turn tool usage into the goal

## Observation

Measuring login rate, prompt count, or feature usage can encourage organizations to optimize visible AI activity rather than improved work.

## Interpretation

Infrastructure transitions matter when work changes: decisions improve, cycle time falls, new outcomes become possible, or old processes disappear.

## Decision relevance

Use adoption metrics as diagnostic signals, then connect them to work depth, outcome quality, cycle time, capability change, or replaced process. Ask what became possible or obsolete because the tool was adopted.

## Limits

Usage metrics remain useful for identifying access, awareness, and training problems; they are simply weak end goals.
