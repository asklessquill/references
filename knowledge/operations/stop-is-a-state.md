# STOP is an explicit system state

## Observation

Autonomous or long-running agents tend to continue expanding scope unless completion and prohibition are represented explicitly.

## Interpretation

A phase should not merely be described as finished. Its terminal state should state what is complete and what must not begin next without new authority.

## Decision relevance

Closeout records should include:

- COMPLETE or equivalent terminal status
- evidence supporting completion
- residual risks or unproven claims
- explicit STOP
- prohibited next phases or mutations

## Limits

STOP is not permanent shutdown. It is a scope boundary pending a new authorized decision.
