# Higher throughput does not guarantee a higher learning rate

## Observation

Forced pauses can sometimes create useful reflection, specification repair, and direction changes. Removing every constraint may increase output while reducing the fraction of work that is actually learned from.

## Interpretation

For R&D systems, the useful metric is not artifacts per hour alone but accepted learning per cycle.

## Decision relevance

Distinguish productive cadence constraints from harmful continuity breaks. Preserve reflection deliberately if capacity upgrades remove a previously useful pause.

## Limits

Long or unpredictable outages usually harm continuity; useful reflection should not be confused with arbitrary unavailability.
