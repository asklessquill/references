# Corrections should preserve the path from wrong to right

## Observation

Silently replacing a wrong conclusion makes the current page cleaner but destroys evidence about how the error happened and which downstream decisions may have inherited it.

## Interpretation

Correction is part of system memory. Supersession should preserve provenance and affected scope.

## Decision relevance

When practical, record the old claim, correction, reason, effective point, and affected artifacts. Let consumers distinguish current truth from historical belief.

## Limits

Routine typo fixes do not need incident-style correction records; use judgment based on semantic impact.
