# Canonicalize before accelerating a system with stronger agents

## Observation

When project state, architecture, or authority is still unstable, adding stronger models, larger quotas, or more autonomous agents can increase output faster than the system can distinguish accepted work from speculative work.

## Interpretation

Before raising throughput, strengthen canonical state, provenance, acceptance boundaries, recovery, and current-state visibility.

## Decision relevance

A useful sequence is stabilize meaning -> prove recovery -> add capacity -> measure whether accepted throughput improves.

## Limits

Exploration can still benefit from high-capability agents if outputs remain isolated in a lab and do not acquire authority automatically.
