# Autonomous activity is not self-sustaining unless it creates external value

## Observation

A system can autonomously research, build, test, and improve while still only consuming resources.

## Interpretation

Operational autonomy and economic autonomy are different milestones. A self-sustaining system needs an external value loop whose realized value exceeds the cost of models, infrastructure, and human intervention over time.

## Decision relevance

Track both capability growth and externally realized value. Avoid treating internal activity volume as evidence of self-sustainability.

## Limits

Not every research system should monetize itself; this principle applies when self-funding is an explicit goal.
