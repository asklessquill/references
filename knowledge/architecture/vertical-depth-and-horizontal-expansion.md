# Vertical depth and horizontal expansion are complementary growth modes

## Observation

A system can improve by going deeper into one problem or by transferring what it learned into adjacent problems. These modes require different search behavior and evidence.

## Interpretation

Vertical growth increases depth, quality, and specialization. Horizontal growth tests generality, reuse, and transfer. Treating both as one undifferentiated roadmap can obscure whether the system is becoming better or merely broader.

## Decision relevance

Track which mode a workstream is pursuing and create deliberate feedback between them: depth should produce reusable abstractions; expansion should reveal where abstractions break.

## Limits

The distinction is analytical; many real tasks contain both modes.
