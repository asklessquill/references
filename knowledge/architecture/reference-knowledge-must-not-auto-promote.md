# Reference knowledge must not auto-promote into authority

## Observation

A useful reference store accumulates hypotheses, experience, model observations, external reports, and generalized lessons. Some will later prove stale, incomplete, or wrong.

## Interpretation

The store is valuable precisely because it can retain useful uncertainty. Automatic promotion would destroy the boundary between evidence and authority.

## Decision relevance

Require an explicit promotion step before reference material controls canonical state, agent permissions, production behavior, or organizational knowledge.

## Limits

Low-risk recommendation systems may consume candidate references directly if uncertainty is preserved and consequences are bounded.
