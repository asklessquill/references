# AI memory should improve continuity without owning canonical state

## Observation

Persistent assistant memory can reduce repeated explanation but may contain stale interpretations, incomplete summaries, or information that is difficult to inspect and version like normal artifacts.

## Interpretation

Memory is best used as a convenience index and contextual aid over durable evidence, not as the sole authority for project semantics.

## Decision relevance

When remembered information conflicts with canonical artifacts, prefer the canonical evidence and correct the projection. Ensure critical continuation knowledge exists in inspectable durable form.

## Limits

Memory systems differ and may support stronger provenance in the future; the boundary should be revisited as capabilities evolve.
